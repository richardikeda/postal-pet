# Contributing

## Review and support

Use the issue forms to report bugs or request features in English, Brazilian Portuguese or Spanish. Work on a fork or a dedicated branch and open a PR to main. @richardikeda owns all paths and reviews contributions. Both version checks must pass and review conversations must be resolved. New commits dismiss prior approvals. Maintainer emergency bypass is available; automatic merge is disabled. Releases are prepared as drafts and require maintainer approval through the release environment.

Open an issue with versions, reproduction steps, expected behavior and sanitized logs. Use a fork and a fix/description or feature/description branch. Submit a PR to main for maintainer review; no automatic merge. Build both adapters, add appropriate regression tests and validate in disposable worlds. Update matching English, Brazilian Portuguese and Spanish documentation together, and preserve all player-facing translations. Keep IDs, official license texts and third-party notices. Contributions must be compatible with LGPL-3.0-or-later.
