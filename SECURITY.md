# Security reports

GitHub Actions are pinned to full commit hashes and restricted to the actions used by this project. CodeQL scans Java sources and workflows on pull requests, main changes and weekly. Java uses source analysis without another Minecraft build; generated code and runtime behavior still require separate testing. Version tags are protected against updates and deletion. The maintainer retains administrative emergency access.

For a suspected vulnerability, use this repository's Security → Report a vulnerability feature. Include affected versions, reproduction steps and impact. Do not publish credentials or private saves. Ordinary gameplay bugs belong in Issues. No response-time guarantee is offered.
