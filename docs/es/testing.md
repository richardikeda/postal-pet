# Pruebas

Ambas builds ejecutan pruebas comunes de contratos/casos de uso, equivalencia de adapters y arquitectura. Registra por separado pruebas en mundos desechables para ambas versiones: inicio, servidor dedicado, recetas, vínculo/desvínculo, buzones cercanos, loros sentados/en el hombro, interfaz/radio, propiedad, descarga, guardado/reinicio y regreso territorial. Incluye fecha, commit, responsable y evidencia real. No envíes mundos privados ni fabriques evidencia.
