# Contribuir

## Revisión y soporte

Usa los formularios de issues para errores o sugerencias en inglés, portugués de Brasil o español. Trabaja en un fork o rama propia y abre PR a main. @richardikeda es responsable de todas las rutas y revisa contribuciones. Los checks de ambas versiones deben pasar y las conversaciones deben resolverse. Los nuevos commits invalidan aprobaciones anteriores. El mantenedor dispone de bypass de emergencia; la integración automática está desactivada. Las releases se preparan como borradores y requieren aprobación mediante el entorno release.

Abre una issue con versiones, reproducción, comportamiento esperado y logs sin datos personales. Usa fork y rama fix/descripcion o feature/descripcion. Envía PR a main para revisión del mantenedor; sin integración automática. Compila ambos adapters, añade pruebas adecuadas y valida en mundos desechables. Actualiza juntas las páginas en inglés, portugués de Brasil y español y conserva las traducciones del juego. Mantén IDs, textos oficiales de licencia y avisos de terceros. Las contribuciones deben ser compatibles con LGPL-3.0-or-later.
