# Informes de seguridad

Las Actions se fijan por hash completo y se restringen a las usadas por el proyecto. CodeQL analiza fuentes Java y workflows en PRs, cambios en main y semanalmente. Java usa análisis de fuentes sin repetir la build de Minecraft; el código generado y el comportamiento en el juego requieren pruebas separadas. Las etiquetas de versión se protegen contra cambios y eliminación. El mantenedor conserva acceso administrativo de emergencia.

Para una posible vulnerabilidad, usa Security → Report a vulnerability en este repositorio. Incluye versiones afectadas, reproducción e impacto. No publiques credenciales ni mundos privados. Los errores normales del juego van en Issues. No se garantiza un plazo de respuesta.
