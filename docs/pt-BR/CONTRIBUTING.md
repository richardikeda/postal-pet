# Contribuir

## Revisão e suporte

Use os formulários de issues para bugs ou sugestões em inglês, português do Brasil ou espanhol. Trabalhe em fork ou branch própria e abra PR para main. @richardikeda é responsável por todos os caminhos e revisa contribuições. Os checks das duas versões devem passar e as conversas precisam ser resolvidas. Novos commits invalidam aprovações anteriores. O mantenedor tem bypass emergencial; merge automático está desativado. Releases são preparadas como rascunhos e exigem aprovação pelo ambiente release.

Abra uma issue com versões, reprodução, comportamento esperado e logs sem dados pessoais. Use fork e branch fix/descricao ou feature/descricao. Envie PR para main para revisão do mantenedor; sem merge automático. Compile ambos os adapters, adicione testes adequados e valide em mundos descartáveis. Atualize juntas as páginas em inglês, português do Brasil e espanhol e preserve as traduções do jogo. Mantenha IDs, textos oficiais de licença e avisos de terceiros. Contribuições devem ser compatíveis com LGPL-3.0-or-later.
