# Relatos de segurança

As Actions são fixadas por hash completo e restritas às usadas pelo projeto. CodeQL analisa fontes Java e workflows em PRs, mudanças na main e semanalmente. Java usa análise de fontes sem repetir a build do Minecraft; código gerado e comportamento no jogo continuam exigindo testes separados. Tags de versão são protegidas contra alteração e exclusão. O mantenedor mantém acesso administrativo emergencial.

Para suspeita de vulnerabilidade, use Security → Report a vulnerability neste repositório. Informe versões afetadas, reprodução e impacto. Não publique credenciais ou saves privados. Bugs comuns do jogo devem ser enviados em Issues. Não há prazo de resposta garantido.
